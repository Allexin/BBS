# BBS

Windows backup system implemented as a Python package with separate manager,
executor, and local control entry points.

The normative requirements are in `BACKUP_SYSTEM_DESIGN.md`; implementation order
and acceptance criteria are in `BACKUP_SYSTEM_IMPLEMENTATION_STAGES.md`.

Operator documentation:

- `docs/CONFIGURATION_MANUAL.md` — configuration and feature setup;
- `docs/OPERATIONS.md` — service lifecycle, deployment, and recovery;
- `docs/DISASTER_RECOVERY.md` — disaster recovery procedures.
