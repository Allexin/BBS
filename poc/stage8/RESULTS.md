# Результаты этапа 8

## Окружение

- Windows 10 Pro, x64.
- Закреплённый restic 0.19.1 Windows amd64.
- Одноразовые source, repository, mirror и restore target только на тестовом диске D.

## Проверки

| Проверка | Snapshot | Mirror |
| --- | --- | --- |
| Отдельный файл с сохранением logical path | Пройдено | Пройдено |
| Поддерево с сохранением структуры | Пройдено | Пройдено |
| Весь source root | Пройдено | Пройдено |
| Полная повторная read-back verification | Пройдено | Пройдено |
| Обнаружение незаметной порчи после записи | Пройдено | Пройдено |
| Сохранение `.restore-incomplete` после ошибки | Пройдено | Пройдено |

Каждый успешный результат создавался в новой технической папке и не использовал
существующие данные. Для snapshot использовался штатный restic restore с `--verify`,
после которого executor независимо перечитал опубликованные файлы. Mirror сверялся с
SHA-256 из durable catalog. Временный каталог stage 8 на D после приёмки отсутствует.

Машинный результат сохраняется локально в
`.poc-work/stage8/restore-hardware-result.json`; временные пути и snapshot IDs в Git
не добавляются.
