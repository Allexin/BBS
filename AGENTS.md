# BBS

## О проекте

BBS — система резервного копирования для Windows. Проект реализуется поэтапно как Python-приложение с автоматизированными проверками и воспроизводимым развёртыванием.

## Источники требований

- `BACKUP_SYSTEM_DESIGN.md` — нормативный источник требований и технических решений.
- `BACKUP_SYSTEM_IMPLEMENTATION_STAGES.md` — порядок реализации и критерии приёмки этапов.

Не копируйте содержимое дизайн-документа в этот файл или вспомогательные инструкции. При расхождении документации и кода сначала уточните или обновите нормативный документ, затем меняйте реализацию.

## Правила работы

- Выполняйте этапы последовательно и не расширяйте их объём без явного решения.
- До финальной приёмки используйте только тестовые конфигурации и тестовые данные.
- Все credentials для локальной разработки и тестов храните только в игнорируемом
  Git каталоге `secrets/`. Используйте их непосредственно из этого каталога и не
  копируйте в Stable.
- При разработке и автоматизированных проверках не читайте и не изменяйте Stable:
  тесты не должны требовать административных прав или вмешиваться в работу
  развёрнутой системы.
- Не добавляйте в репозиторий секреты, персональные данные, реальные пути и параметры production-среды.
- Сохраняйте совместимость с Windows и не подменяйте выбранные проектом технологии без согласования.
- Для каждого изменения добавляйте или обновляйте проверки, соответствующие его риску.
- Коммиты должны быть небольшими, тематическими и оставлять рабочую ветку в проверяемом состоянии.
